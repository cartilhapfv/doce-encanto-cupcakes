# Requisitos iniciais — Doce Encanto

## 1. Visão do projeto

O Doce Encanto é um projeto acadêmico de aplicativo para uma loja fictícia de cupcakes gourmet. A proposta é facilitar a apresentação dos produtos e o envio de pedidos pelos clientes.

## 2. Requisitos funcionais

| Código | Requisito |
|---|---|
| RF01 | O sistema deve apresentar a loja e suas informações principais. |
| RF02 | O sistema deve exibir um catálogo de cupcakes. |
| RF03 | Cada produto deve apresentar nome, descrição e preço. |
| RF04 | O cliente deve conseguir selecionar produtos e quantidades. |
| RF05 | O sistema deve apresentar um resumo dos itens selecionados e do valor do pedido. |
| RF06 | O sistema deve permitir informar nome e telefone para contato. |
| RF07 | O sistema deve permitir informar o endereço de entrega. |
| RF08 | O cliente deve conseguir selecionar uma forma de pagamento. |
| RF09 | O sistema deve apresentar uma confirmação/resumo do pedido. |

## 3. Requisitos não funcionais

| Código | Requisito |
|---|---|
| RNF01 | A interface deve ser simples e intuitiva. |
| RNF02 | A aplicação deve funcionar adequadamente em telas de celular. |
| RNF03 | Os textos, botões e informações devem ser legíveis. |
| RNF04 | O sistema deve apresentar os dados do pedido de forma organizada. |
| RNF05 | O protótipo deve utilizar dados fictícios e não solicitar dados bancários reais. |

## 4. Fluxo principal previsto

1. O cliente acessa a página inicial.
2. Consulta o catálogo.
3. Escolhe um ou mais cupcakes e suas quantidades.
4. Confere o resumo do pedido.
5. Informa seus dados de contato e endereço.
6. Seleciona a forma de pagamento.
7. Visualiza a confirmação do pedido.

## 5. Fora do escopo inicial

- Processamento real de cartões ou armazenamento de dados bancários.
- Integração real com entregadores.
- Gestão avançada de estoque.
- Painel administrativo completo.

Essas funcionalidades poderão ser consideradas apenas se houver tempo e recursos.

## 6. Observação

Estes requisitos são uma base inicial para o protótipo e devem ser revisados conforme a ferramenta escolhida e os testes realizados.
