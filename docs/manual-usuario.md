# Manual do usuário — Doce Encanto

## 1. Apresentação

Este manual explicará como utilizar o protótipo do aplicativo Doce Encanto — Cupcakes Gourmet. O manual será atualizado após a construção da versão funcional, com capturas de tela reais.

## 2. Acesso ao aplicativo

- Endereço de acesso: será informado após a publicação.
- Dispositivo recomendado: celular ou navegador com visualização mobile.
- Não é necessário informar dados reais para testar o protótipo.

## 3. Como realizar um pedido

1. Acesse a tela inicial.
2. Abra o catálogo de cupcakes.
3. Selecione um produto para consultar seus detalhes.
4. Escolha a quantidade e adicione o produto ao carrinho.
5. Repita o procedimento se desejar outros produtos.
6. Abra o carrinho e confira os itens e o valor total.
7. Informe nome e telefone fictícios.
8. Informe um endereço fictício para entrega.
9. Selecione uma forma de pagamento demonstrativa.
10. Confira os dados e visualize a confirmação.

## 4. Observações importantes

- O aplicativo é um protótipo acadêmico de uma loja fictícia.
- Não são realizadas cobranças reais.
- Não informe números de cartão, senhas ou dados bancários.
- Utilize informações fictícias durante as demonstrações.
