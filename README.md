# Doce Encanto — Cupcakes Gourmet

Projeto acadêmico de desenvolvimento de um aplicativo para uma loja fictícia de cupcakes gourmet, dando continuidade ao PIT I.

## Objetivo

Disponibilizar aos clientes uma forma simples de conhecer os produtos e realizar pedidos, com escolha de sabores e quantidades, identificação do cliente, informações de entrega, seleção da forma de pagamento e confirmação do pedido.

## Escopo inicial

- Apresentação da loja.
- Catálogo de cupcakes com nome, descrição e preço.
- Visualização dos detalhes dos produtos.
- Seleção de produtos e quantidades.
- Resumo do pedido.
- Identificação do cliente e endereço de entrega.
- Escolha da forma de pagamento.
- Confirmação do pedido.

## Situação do projeto

Este repositório organiza a documentação e os arquivos do PIT II. A aplicação ainda precisa ser construída e validada. As tecnologias, o endereço de publicação, os testes com participantes e os resultados serão registrados à medida que forem efetivamente definidos e realizados.

## Observação acadêmica

Os dados de produtos e clientes usados no protótipo devem ser fictícios. Não devem ser solicitados nem armazenados dados bancários reais.
